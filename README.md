# Immersive Anti-Gravity Developer Portfolio

A premium, recruiter-friendly developer portfolio featuring cinematic 3D scroll physics, an interactive tech galaxy visualizer, and verified professional credentials. 

## 🌐 Live Preview

Explore the live experience at: **[biyyanihari.netlify.app](https://biyyanihari.netlify.app)**

---

## 🛠️ Engine Specs (Tech Stack)

* **Frontend Engine:** React.js, Tailwind CSS, Framer Motion
* **Smooth Scrolling:** Lenis Scroll Engine
* **Background Atmosphere:** tsParticles Physics
* **Icons & Assets:** Lucide React

---

## 🚀 Key Features

* **Anti-Gravity Space Theme:** Dark cyberpunk aesthetic with subtle neon gradients and interactive holographic interfaces.
* **Apple-Style Sticky Scroll:** High-performance sticky project cards locking smoothly into view.
* **3D Holographic Hover Cards:** Custom cursor-tracking tilt grids (`rotateX`, `rotateY`) and glass reflections.
* **Interactive Tech Galaxy:** Orbiting skill planetary system with counter-rotation upright texts.
* **Verified Credentials:** Hand-mapped brand-colored certifications displaying instant Credly verifications.
* **Streamlined Resume Section:** Recruiter-friendly centered glass CTA card for immediate PDF download.

## 💻 Local Setup & Development

To boot the system environment locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/hari07-git/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
